# LZSync 设计准则

> UI/UX 唯一权威文档。改任何前端样式、组件、文案、图标前先读这份；与 `docs/design-mockup/` 配套使用（SVG 即视觉事实源）。

## 哲学

**数据是主角，客户端只是来源。** 用户在 LZSync 里管理的是「谱面集/收藏/皮肤/成绩」本身，不是「哪个 fork」。侧栏按数据域划分；客户端退级为「客户端」页，仅注册/移除/看状态。

**界面不解释。** 如果某个文案在教用户怎么用，说明组件没设计对。所有非必要解释性话术都删。

**视觉参考 osu! 官方设置页。** 深紫灰底、单列垂直流、滑杆/开关右置、分组靠标题不靠卡片。

## 硬约束

### 颜色

- **不用任何渐变。** 按钮、进度条、激活态、图标、徽标——一律纯色。品牌紫 `#7C6CF0` 是主强调色；青 `#57C8E8` 仅作辅助与图标弧段色，不进界面渐变。
- **深色优先。** 基底 `#0E1116`，抬起 `#161B22`，卡片 `#1D232C`，hover `#262D38`，边框 `#2E3540`。浅色变体暂缓，将来反转映射。
- **四端指示色只作小圆点**：lazer `#66CCFF`、delta `#C88BF5`、ez2lazer `#FF7EB6`、g0v0 `#7CE8B8`、未注册 `#3A4150`。**不渲染客户端名**；端名只在悬浮明细里出现。
- **同步状态语义色**：一致 `#3DDC97`、有更新 `#7C6CF0`（品牌紫）、冲突 `#F06C7A`、需确认 `#F0B35C`、仅目标有 `#8B93A1`。配色逻辑：绿=安全、紫=有活要干、红=要处理、黄=待拍板、灰=旁支。

### 谱面集封面

- **永远用真实封面**：谱面集文件夹内第一张图作为行背景。优先选择文件名（不含扩展名）等于 `bg` 或 `background` 的图（**大小写不敏感**），找不到再回退到文件夹第一张图。
- **禁止联网**：不查 osu!api，不调外部封面服务。filestore 已按内容寻址拿到全部文件。
- **遮罩做法**：封面上盖一层 `rgba(0,0,0,0.5)` 单色罩即可，不加渐变方向。封面仅作氛围，文字可读就行。

### 数据行结构（谱面集）

```
[封面横条 80px]
  ✓ 复选框          曲名（17px 粗体）
                   艺术家（12px 次色）
                   ●●○ 模式点 · 12 难度 · 156 MiB
                                          ┌──────┐
                                          │ 3/4  │ ← 固定 110px 宽，居中
                                          │ 有更新│
                                          └──────┘
```

- **右侧 `x/y` 块**：分子=「该数据已在多少端是最新版」，分母=「已管理端总数」。颜色随状态语义色，**不显示「端最新」等解释文字**。
- **悬浮明细**：hover `x/y` 块向上浮出 250×~120 浮层，逐端列出（色点+端名+`✓`/`⚠ 旧`/`—`），末尾一行给 hub 版本号或异常摘要。
- **其他数据形态行高**：收藏/皮肤 56px（无封面，图标块代替）；成绩行 48px（图标+玩家+曲名+分数）。

### 文案

| 场景 | 写法 | 不写 |
|---|---|---|
| 数据行状态 | 一致 / 有更新 / 冲突 / 需确认 / 仅目标有 | 待更新、待拍、弱键、tombstone |
| 同步步骤 | 拉取 → 写入 → 还原 | 收集、投放、生成计划、守护进程、基线、三方 |
| 端角色开关 | 拉取 / 写入 | 来源端、目标端、source、target |
| 待处理 | 冲突 / 需确认 / 不支持 | 交集外、全局交集、tombstone |
| 顶部按钮 | 同步 | 生成投放计划、执行投放 |
| 管理页 | 客户端 | 数据源、库、注册的 fork |
| 悬浮层端状态 | `✓` / `⚠ 旧` / `—` | 「已同步」「旧版本」「不存在」 |
| 已选条 | `已选 3` + `同步` 按钮 | 「点击此处批量应用所选更改」 |

**规则**：名词用实体名（谱面集、收藏、皮肤、成绩、客户端），动词用最小集（拉取/同步到/还原/移除/注册/扫描）。需要解释的概念不许出现。

### 侧栏

```
LZSync
  概览
  ─────
  谱面集        ← 高亮 = 当前页
  收藏
  皮肤
  成绩
  同步
  ─────
  [底部小卡] 客户端 · 4 端 · 1 运行中
```

- 无「库管理」「对比预览」这类实现导向命名。
- 顶部固定搜索框（全局搜索任意数据项）+ 右上角警告胶囊（有客户端运行时亮）。
- 激活态：紫底白字，无渐变无描边。

### 同步按钮与同步页

行为语义以 `docs/design.md` §0 为准：**顶栏常驻「同步」按钮 = 按设置对全部客户端跑一轮**（拉取全部来源 → 判定 → 写入全部目标）。「计划」是内部概念，不暴露给用户。

- 顶栏按钮：首次点击展开确认条（`写入 3 端 · 128 项` + 跳过的客户端色点），再点「同步」执行；执行中按钮变进度并可取消。
- 同步页：本轮进度（快照 → 写入，逐端一行：色点+进度条，运行中的客户端行边框转黄并标跳过）→ 完成后逐端报告（新增/更新/跳过计数）→ 待处理（冲突 / 需确认 / 不支持 计数，点击跳到对应数据页筛选）。
- 底部：还原条（选目标+选备份路径+还原按钮）。

### 设置页「同步范围」

置顶分组，osu! 设置页式开关右置：

- 板块：谱面集 / 收藏 / 皮肤 / 成绩 / 键位 / 规则集设置 / Mod 预设 / game.ini，每项一个开关。
- 客户端：每端一行（色点+端名），右侧两个开关「拉取」「写入」（对应来源/目标角色）。

## 图标

三段圆弧箭头循环（青→紫→粉顺时针）+ 中心白点（hub）。各弧段之间留缝，箭头在弧段末端，指向下一弧起点——循环=收集/投放/再收集。

- `resources/icon.png` 1024×1024 用深色版（底 `#1D232C`，圆弧三色）
- 另出浅色底版备任务栏/通知用
- 三段弧+中心点在 SVG 里拆成 4 个图层，搬 Figma 直接编辑

## 不做的事

- **不解释概念**：不写「这是什么」「怎么用」「为什么」类长文案；需要解释的功能重新设计
- **不做客户端个人化**：四端色点大小统一 8px，不画 logo、不画头像、不做渐变标识
- **不做响应式**：目标是桌面 app，假定 1280+ 宽度；移动/小屏不在范围
- **不做动画**：除了进度条与悬浮层出现/消失，其他动效不加
- **不做多语言切换**：界面中文一档；i18n 仅保留 `t()` 层，不做 UI 语言切换开关

## 与实现的对齐

- 图标 → `resources/icon.png`（1024²），`main.go` embed 不变
- fork 色 → `src/style.css` `--fork-{id}` 变量，数据行 `x/y` 块与悬浮层端行用
- 数据行状态 → `src/mygo.ts` 的 `Category`/`Action` 枚举映射到上述状态词
- 封面 → `internal/filestore` 提供按谱面集取「第一张图」的接口（后端），前端只拿 URL
- 悬浮层 → `src/ui.ts` 加 `popover()` 辅助函数
- 文案 → `src/i18n.ts` 全键重写，t() 包裹
