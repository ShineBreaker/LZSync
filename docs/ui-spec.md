# LZSync 设计准则

> UI/UX 唯一权威文档（v2，2026-10-27）。改任何前端样式、组件、文案、图标前先读这份。同步行为语义以 `docs/design.md` §0 为准，本文只定义它在界面上长什么样。`docs/design-mockup/` 是 v1 历史稿，仅 `icon-master.svg` 仍有效。

## 0. 出发点

§0 把 LZSync 定义为：**一座收全的库 + 若干客户端 + 一个「同步」按钮**。能判定的改动自动传播，判不准的留给人。所以用户只做三件事：

1. **接线**（一次性）：哪些客户端参与、各自拉取还是写入、哪些板块参与。
2. **按同步**：看到数据流进库、再流向各端。
3. **拍板**：处理少数判不准的条目。

浏览数据是第二位的需求：看库里有什么、每样东西在哪些端。

界面围绕这三件事组织；任何不服务它们的元素都删。

## 1. 原则

- **界面即解释。** 方向用箭头、参与与否用实线/虚线、归属用色点表达；若一个元素需要一句话教用户怎么用，就重新设计这个元素。界面上不出现任何说明性句子，提示只允许出现在悬浮层里且只写名词（端名、状态词）。
- **一个视觉语言，到处复用。** 学一次就够：
  - **实线 = 参与，虚线 = 不参与**（连线、板块胶囊同一套）。
  - **实心色点 = 该端已有，空心色环 = 下一次同步会送达，灰点 = 不会有。**
  - **左缘色条 = 需要你处理**（红：冲突，琥珀：待确认）；没有色条就不用管。
- **只有一种确认方式。** 一切写游戏数据的动作都是两步：按钮第一次点击变成「写入 N 项」，第二次才执行。
- **空即是好。** 没有冲突就不渲染待处理区，不写「暂无冲突」。
- **不暴露实现概念。** 界面不出现：中枢、hub、计划、收集、投放、基线、三方、交集、tombstone、presence、来源端、目标端。

- **去掉顶栏。** 原全局搜索框无功能、运行警告属于客户端，二者各归其位（搜索进资料库页头，运行态进客户端节点）。

- **设置页**只剩低频项：语言、存储路径、引擎/链接诊断、进程名单。同步范围搬到同步台。
- 侧栏「同步」右侧徽标 = 待处理条数（红底白字，0 不显示）；同步进行中显示为一个小进度环。资料库四项右侧是库内条数（低色）。

三列网格：客户端列（约 220px）｜连线列（自适应）｜库卡（约 280px，纵向跨越全部客户端行）。连线贴到库卡左缘，形成辐条汇向中心的观感。窗口默认 1080×720 下必须完整可用。

### 3.2 连线 = 角色开关 + 进度条

每个客户端一条连线，由上下两条轨道组成：

- **上轨：拉取**，箭头指向库（▶）。
- **下轨：写入**，箭头指向客户端（◀）。

每条轨道是独立开关：点击切换。**开 = 实线带箭头，关 = 虚线无箭头**。悬浮只显示「拉取」/「写入」。两条都关 = 该端不参与（整条虚线）。开关即时保存（失败回滚并提示）。

同一条连线在同步时就是进度条：

| 阶段 | 连线表现 |
|---|---|
| 拉取中 | 上轨按该端进度从左向右填充品牌紫 |
| 待确认 | 下轨中央浮出「+N」胶囊（该端将写入的条目数）；N=0 不显示 |
| 写入中 | 下轨从右向左填充 |
| 完成 | 下轨胶囊变为「✓ N」（绿）或「✕」（红）；悬浮显示新增/更新/跳过计数、备份时间、错误原文 |
| 本轮跳过 | 整条连线降到 40% 透明度，客户端节点显示「运行中」 |

### 3.3 客户端节点

- 常态：色点 + 端名；次行低色小字「磁盘版本 · files 体积」。
- 运行中：色点外圈琥珀色环，次行换成琥珀色「运行中」。
- 未识别：灰点 + 「?」；次行是四个可选端的色点（悬浮显示端名），点哪个即指认为哪个。
- 悬浮出现右侧「⋯」：菜单两项「还原…」「移除」。
  - **还原…**：弹系统文件选择框（默认打开备份目录）→ 节点原地变为「还原 10-26 23:27」+［还原］［✕］两步确认。
  - **移除**：节点原地变为红色［移除］［✕］两步确认。移除不碰磁盘。
- 末行虚线「＋」节点：点击出两个图标按钮「扫描」「选择文件夹…」。另外把文件夹直接拖进窗口任意位置即注册（拖入时「＋」节点高亮）。
- 首次打开且没有任何客户端时自动扫描一次；仍为空时页面只剩库卡与「＋」节点，「同步」不可点——唯一能点的就是「＋」。

### 3.4 库卡

- 顶部应用图标。
- 八个板块胶囊（谱面集/收藏/皮肤/成绩/键位/规则集设置/Mod 预设/game.ini），前四个带库内条数。**点击切换参与与否：实线 = 参与，虚线 + 低色 = 不参与**（与连线同一语言）。即时保存。
- 底部主按钮，即一轮同步的状态机：

| 状态 | 按钮 | 旁边 |
|---|---|---|
| 空闲 | 同步 | — |
| 拉取中 | 拉取中…（禁用） | ✕（取消） |
| 待确认，N>0 | 写入 N 项 | 取消 |
| 待确认，N=0 | 已是最新（绿，禁用，约 2 秒后回空闲） | — |
| 写入中 | 写入中…（禁用） | ✕（取消） |
| 完成 | 回到「同步」 | — |

N = 全部目标端将写入项之和。没有客户端、或没有任何写入轨开启时按钮禁用。

### 3.5 待处理

同步台下方，只列判不准、需要人拍板的条目：冲突（全部板块，含键位/设置/Mod 预设/game.ini）与同名谱面待确认。已删除项不在此列（删除是用户自己的意图，去资料库「已删除」里恢复）；不支持项无可拍板之处，只出现在连线悬浮的计数里。

- 标题「待处理 N」；N=0 整区不渲染。
- 行：左缘色条 + 板块小字 + 条目名 + 持有端色点 + 右端展开箭头。
- 展开（冲突）：每个持有端一张**取值卡**（色点 + 该端取值摘要），点哪张即「以它为准推到全部端」；末尾一张虚线卡「保留差异」（各端维持现状，此后不再提示，除非某端再改）。缺席端的卡置灰不可选。
- 展开（待确认）：一张卡「更新为新版本」；不选则维持现状、条目继续留在此处（配对否决待后端支持后再加「不是同一谱面」卡）。
- 选定后行收起，右端显示所选（端色点或「=」），并进入**暂存**（§5）。

## 4. 资料库页（谱面集 / 收藏 / 皮肤 / 成绩）

### 4.1 页头

```
谱面集  3,087                   [⌕ 搜索      ]  [全部 | 待处理 2 | 已删除 5]
```

- 搜索框即时过滤当前页（标题/艺术家/作者/名称，大小写不敏感）。
- 分段筛选：全部 / 待处理（冲突 + 待确认）/ 已删除。计数为 0 的分段不显示；只剩「全部」时整个分段控件隐藏。

### 4.2 数据行

```
▌[封面横条 80px                                              ]
▌ 曲名（17px 粗体）                                ● ● ◯ ·
▌ 艺术家（12px 次色）
▌ #1656406 · 删除于 2026/10/17
```

- 页面列出**库里的全部条目**（不是只列差异）。
- 右侧**覆盖点**：每个已注册客户端一个 8px 点，顺序与同步台一致：
  - 实心端色 = 该端已有；
  - 空心端色环 = 下一次同步会送达（新建或更新为新版本）；
  - 红色环 = 该端取值与他端冲突；
  - 琥珀环 = 该端持有疑似旧版本，待确认；
  - 灰点 = 该端没有且不会有（已删除、不支持、未开写入）。
  - 悬浮覆盖点：逐端「色点 + 端名 + 状态词」，状态词取 `✓ / 将写入 / 冲突 / 待确认 / 已删除 / 不支持 / 不写入 / —`，末行可附原因原文。
- 左缘色条：冲突红、待确认琥珀；已删除行整体降为 60% 透明度。
- 点击需处理的行原地展开与待处理区相同的取值卡；已删除行展开为一张「恢复」卡。
- 悬浮任意行时左侧浮出勾选框；勾选即加入暂存（「只同步这几项」）。有勾选时所有行常显勾选框。
- 封面规则：谱面集文件夹内文件名（不含扩展名，大小写不敏感）为 `bg`/`background` 的图优先，否则第一张图；不联网；封面上盖 `rgba(0,0,0,0.5)` 单色罩。
- 行高：谱面集 80px（有封面）；收藏/皮肤 56px；成绩 48px。长列表按 80 行一页懒追加。

## 5. 暂存条

所有「拍板」与「勾选」进入同一个暂存区，跨页保留。暂存非空时窗口底部居中浮出：

```
             ┌──────────────────────────────────┐
             │  已选 3     [同步]   ✕            │
             └──────────────────────────────────┘
```

- ［同步］：先落「保留差异」类决定（只改库内记录，立即生效），再对其余项发起「只同步所选」的一轮；暂存条原地变成「写入 N 项」两步确认，与库卡按钮同一状态机、同一组连线进度（在同步台时可见）。
- 只含「保留差异」时无需二次确认，点一下即完成。
- ✕ 清空暂存。完成后暂存条以「✓ N」停留约 2 秒后消失，待处理与资料库刷新。

## 6. 视觉

### 6.1 颜色

- **不用任何渐变**，一律纯色。深色唯一主题。
- 底色：基底 `#0E1116`、抬起 `#161B22`、卡片 `#1D232C`、悬浮 `#262D38`、边框 `#2E3540`、强边框 `#4A5265`。
- 文字：高 `#E9EDF3`、中 `#AAB2BF`、低 `#6B7280`。
- 品牌紫 `#7C6CF0`：主按钮、激活态、进度填充、选中态。青 `#57C8E8` 只用于图标。
- 语义：成功 `#3DDC97`、冲突 `#F06C7A`、待确认/运行中 `#F0B35C`、中性 `#8B93A1`。
- 客户端色**只用于圆点与色环**：lazer `#66CCFF`、delta `#C88BF5`、ez2lazer `#FF7EB6`、g0v0 `#7CE8B8`、未知 `#3A4150`。
- 「关」态统一：1.5px 虚线 `#4A5265` + 低色文字。

### 6.2 字号与形状

- 页标题 18px/700；行标题 17px/700（谱面集）、14px/600（其他）；正文 12px；次要 11px；徽标 10px。
- 圆角 6/8/12；按钮高 32px（主按钮 40px）；胶囊全圆角。
- 图标为内联 SVG（1.5px 描边，16px），集中在 `src/ui.ts` 的 `icon()`。

### 6.3 动效

只有三处：进度填充、悬浮层出现、暂存条出现。均不超过 150ms。

## 7. 文案

| 场景 | 写法 | 不写 |
|---|---|---|
| 连线悬浮 | 拉取 / 写入 | 来源端、目标端、source、target |
| 主按钮 | 同步 → 写入 N 项 → 写入中… | 生成计划、执行投放、确认执行 |
| 待处理 | 冲突、待确认、保留差异、更新为新版本 | 以中枢为准、弱键、三方判定 |
| 覆盖点悬浮 | ✓ / 将写入 / 冲突 / 待确认 / 已删除 / 不支持 / 不写入 / — | 已同步、presence、tombstone |
| 暂存条 | 已选 N · 同步 | 「点击此处批量应用」 |
| 客户端菜单 | 还原… / 移除 | 解除注册、恢复备份文件 |
| 添加客户端 | 扫描 / 选择文件夹… | 自动发现、手动注册路径 |

名词只用实体名（谱面集、收藏、皮肤、成绩、客户端），动词只用最小集（同步、拉取、写入、还原、移除、扫描、恢复）。错误与后端原文只出现在悬浮层或右下角短时提示里。

## 8. 不做的事

- 不做顶栏、全局搜索、全局运行警告条。
- 不在界面上写任何「这是什么 / 怎么用 / 为什么」。
- 不做客户端个性化：不画 logo/头像，客户端色只作 8px 点。
- 不做响应式；目标窗口 1080×720 起。
- 不做浅色主题。
- 不做后台/定时同步入口（§0 不做项）。

## 9. 与实现的对齐

| 界面 | 后端 |
|---|---|
| 客户端节点 | `LibraryService.List/Scan/Register/AssignFork/Remove` |
| 连线开关、板块胶囊 | `SettingsService.GetSyncScope/SetSyncScope` |
| 板块胶囊条数、侧栏条数 | `CompareService.HubCounts` |
| 主按钮状态机 | `SyncService.PrepareRun → CommitRun`；取消 `SyncService.Cancel` |
| 连线进度 | `sync-progress` 事件，按 `ProgressEvent.ForkID` 分派 |
| 待处理 | `CompareService.ListConflicts` + `CompareService.Library("beatmap_set")` 中待确认行；取值卡 `CompareService.UnitConflict` |
| 保留差异 | `SyncService.KeepDifference` |
| 资料库页 | `CompareService.Library(kind)`（全部条目 + 逐端覆盖状态）、`CoverImage` |
| 暂存条同步 | `SyncService.PrepareSelected → CommitRun` |
| 还原… / 选择文件夹… | `DialogService.PickFile / PickFolder`（系统对话框）+ `SyncService.RestoreBackup` / `LibraryService.Register` |
| 拖入文件夹 | mygo-runtime `onFileDrop` → `LibraryService.Register` |

前端文件：`src/main.ts`（壳与路由）、`src/ui.ts`（DOM 助手、图标、悬浮层、提示）、`src/state.ts`（暂存区 + 一轮同步状态机，全页面共享）、`src/pages/{home,library,settings}.ts`、`src/pages/decide.ts`（取值卡组件，待处理区与资料库共用）、`src/i18n.ts`、`src/style.css`。
